# Climate starter kits

Each folder is one dataset: data.csv, README.md, fetch.py, and fetch.js.
Open data.csv in a spreadsheet, or run fetch.py for a fresh response from the direct URL.

- emolt: eMOLT bottom temperature
- ndbc: NOAA buoy 44013, Boston
- berdo: Boston BERDO reporting, 2021
- ej: MassGIS environmental justice block groups
- tides: NOAA Boston tide gauge 8443970
- charles: USGS Charles River at Waltham
- landfills: Renewable projects at Massachusetts landfills
- utilities: Electric utility by Massachusetts town
- transmission: Transmission lines crossing Massachusetts
- fish: Diadromous fish monitoring stations
